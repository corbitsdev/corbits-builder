# Product Requirements: Daily Streak & Habit Tracker

## Functional Requirements

1. **Today Summary Header**: Shows today's formatted date, completed count out of total active habits (e.g. `3 of 4 completed today`), and longest active streak.
2. **Habit Check-In List**: Each row displays the habit name, category badge, reminder time (e.g. `07:30`), 7-day dot strip, current streak in days, and a one-click check-in toggle.
3. **Add / Edit Habit Dialog**: Allows creating a habit with name, category (`Health`, `Focus`, `Mindfulness`), and reminder time.
4. **Filter & Empty States**: Filter between `All`, `Remaining today`, and `Completed today`, with a clear empty state when all habits for today are done.
