# Acceptance Checklist — Clinical Trial Patient Intake & Consent Portal

- [x] Coordinator queue displays candidates with eligibility status, signed consent version, and re-consent warnings.
- [x] Updating an inclusion or exclusion criterion recalculates candidate eligibility and appends an audit event.
- [x] Enrollment is refused with a clear reason until all criteria pass and active IRB consent is countersigned.
- [x] Audit trail view filters chronological events by subject code and action type.
