# Approaches: Field Service Dispatch Board

## Option 1: Queue + Technician Capacity Split View (Recommended)

Combine a filterable work-order queue and SLA alert strip on the left with a contextual assignment and status drawer on the right, backed by relational work-order and technician tables.

## Option 2: Full-Screen Drag-and-Drop Gantt Timeline

Render a 24-hour horizontal Gantt grid with draggable blocks per technician.

## Option 3: Map-First Geo Pin Board

Center the entire product on a full-bleed map canvas with floating overlays.
