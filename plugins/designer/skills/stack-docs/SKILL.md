# Stack docs

The starter's code and AGENTS.md show how the app uses each tool. For an API
detail beyond them, start at the official llms.txt with web_fetch_exa, then
follow its links; search with web_search_exa only when it does not cover it.

- Bun: https://bun.com/llms.txt
- Hono: https://hono.dev/llms.txt
- Vite: https://vite.dev/llms.txt
- React: https://react.dev/llms.txt
- React Router: https://reactrouter.com/home
- TanStack Query: https://tanstack.com/llms.txt
- Tailwind CSS v4: https://tailwindcss.com/docs

@corbits/react-ui is this project's own kit; its props are in the react-ui
skill, not on the web.
